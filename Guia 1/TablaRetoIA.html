Contenidos de la Guía 1

Contenido ya estudiado en el curso Contenido nuevo
Listas HTML (<ul> y <li>): Utilizadas para estructurar la barra de navegación y las sucursales del pie de página. Variables CSS (:root y var()): Definir una paleta de colores global reutilizable (como el color corporativo --motocity-red), lo que permite modificar la identidad visual del sitio completo desde una sola línea de código.
Modelo de caja (margin, padding, width, height, border): Empleado para dimensionar, separar y enmarcar todos los contenedores y tarjetas del sitio. Flexbox (display: flex): Alinear y distribuir de manera inteligente los elementos en una sola dirección (por ejemplo, acomodar el logo y los enlaces del menú horizontalmente).
Ajuste de tamaño (box-sizing: border-box): Aplicado universalmente para asegurar que los rellenos y bordes se incluyan dentro de la anchura total establecida. CSS Grid (display: grid): Crear cuadrículas bidimensionales automatizadas (auto-fit y minmax) para que las tarjetas de las motocicletas se reacomoden perfectamente según el tamaño de la pantalla.
Selectores avanzados y descendientes: Utilizados para apuntar a elementos específicos que se encuentran dentro de contenedores anidados. Posicionamiento Fijo (position: fixed): Mantener la barra de navegación superior estática y anclada en la parte superior de la pantalla mientras el usuario realiza scroll hacia abajo.
Pseudo-clases de interacción (:hover): Implementadas en los botones y tarjetas para alterar visualmente los estilos cuando el usuario pasa el cursor sobre ellos. Diseño Responsivo (@media queries): Detectar las dimensiones de la pantalla del usuario (como en dispositivos móviles) para adaptar y reestructurar las reglas de diseño automáticamente.
Estética y efectos CSS3 (border-radius y box-shadow): Utilizados para redondear las esquinas de los contenedores y darles un efecto de relieve o profundidad. Transiciones y Transformaciones (transition y transform): Generar animaciones fluidas y suaves (como el aumento de tamaño o la elevación) cuando ocurren interacciones en los elementos.
Filtros visuales y gradientes (backdrop-filter y linear-gradient): Aplicar efectos gráficos modernos, como el desenfoque estilo vidrio esmerilado en el menú y capas oscuras translúcidas sobre las imágenes de fondo.
JavaScript Básico (<script> y addEventListener): Proveer interactividad dinámica al sitio para que, al presionar el botón de menú móvil en un teléfono, la lista de navegación aparezca o desaparezca correctamente.
